# Acer Crate 1.0.1 — 11 ноября 2026

## Выполнено

- При обычном открытии и возврате окна добавлены восстановление, подъём в порядке окон и запрос фокуса. Повторный запуск передаёт разрешение на фокус существующему процессу. Постоянного закрепления поверх окон нет.
- Чёрный фон тёмной темы распространяется на окно, сайдбар, карточки, настройки и всплывающие элементы; Mica удалена.
- В настройках доступны произвольные непрозрачные цвета акцента, текста и фона сайдбара: палитра, HEX и сброс. Кисти существующих страниц обновляются на месте; графики используют выбранные цвета.
- Показания вентиляторов на главной читаются непосредственно из последней телеметрии по FanId. Редактор ручного охлаждения больше не является источником RPM. Устаревшие и отсутствующие значения очищаются, фактический ноль сохраняется.
- В настройках показана версия 1.0.1. Кнопка удаления запускает установленный деинсталлятор после подтверждения.
- Установщик по умолчанию выбирает D:\Acer Crate, принимает выбранную папку, хранит резервную копию на диске назначения и ограничивает запись в каталог службы администраторами и SYSTEM.

## Оставшийся шаг установки

32-битный makensis из проверенного архива NSIS не запускается в изолированной среде: Windows возвращает Illegal System DLL Relocation. Файл Setup.exe здесь пока не создан. Скрипт `Update-AcerCrate.cmd` запускает подготовку установщика из уже опубликованных файлов в обычной Windows, затем открывает мастер установки. Промежуточный итог записывается в `.acercrate-dev/outputs/update-status.json`.

Установленная версия 0.3.6 не заменялась. Для применения 1.0.1 требуется запуск этого скрипта владельцем компьютера и подтверждение UAC установщика.

Визуальная и аппаратная проверка новой версии не завершена: Computer Use отказал в доступе к Acer Crate с сообщением «Computer Use was not approved to use Acer Crate». Причину фактического поведения вентиляторов на устройстве нельзя считать подтверждённой только программными тестами.

Остаётся прежнее предупреждение NU1902 для транзитивной зависимости MessagePack 2.5.302. Протокол и версии этой зависимости в данном изменении не обновлялись.
