# Acer Crate

Приложение для Acer Nitro AN515-58 на основе OpenSense 0.3.6. Windows 11 x64, .NET 10, WinUI 3. Исходная лицензия GPL-3.0 сохранена. Это самостоятельная модификация, не официальное приложение Acer.

## Запуск

Версия Acer Crate: **1.1.0**. Папка установки по умолчанию — `D:\Acer Crate`; её можно выбрать в установщике. Среды .NET и Windows App SDK включены в поставку, отдельно устанавливать .NET не требуется. Управление устройством выполняет служба `AcerCrate` из подпапки `Service`.

Основная поставка — один файл `AcerCrate-Setup-x64.exe`. Он устанавливает приложение, службу и встроенные среды запуска в выбранную папку, создаёт ярлык и запись удаления в параметрах Windows. Настройки, пресеты и текущее состояние автозапуска сохраняются при обновлении. Резервная копия установки создаётся на диске назначения. Архив соответствующих исходников и GPL находятся в установленной папке `Source`. Установщик работает без скачивания дополнительных компонентов.

Изменения 1.1.0: библиотека игр, журналы, страница графики с проверкой MUX, немедленное уведомление Ctrl+Alt+F, обновлённые страницы кроме главной, английский при первом запуске и имена службы/настроек AcerCrate. Главная сохранена без обводок. Совместимость определяется возможностями прошивки; все модели с 2021 года физически не проверены. Гибридный режим не равен «только iGPU».

Изменения 1.0.1:

- Обычное открытие, повторный запуск и возврат из трея поднимают окно на передний план. Окно не закрепляется поверх остальных: обычное переключение приложений сохраняется.
- Основная область тёмной темы остаётся чёрной. На главной карточки показаний, режимов, дисков и графиков имеют прозрачный фон и тонкую границу. На отдельных страницах клавиатуры и охлаждения сохранены слегка светлее подложки #0C1010. Сайдбар сохраняет прежнюю компоновку и разделительную линию. Единый акцент из настроек применяется к меню, выбранному режиму, индикаторам и значку экранного сообщения. Цвет текста и фон боковой панели выбираются отдельно палитрой или HEX.
- Индикаторы вентиляторов главной читают RPM из последней телеметрии по идентификатору вентилятора, независимо от редактора охлаждения. Через шесть секунд без новых данных значение очищается.
- В настройках видна версия 1.0.1 и есть кнопка удаления с подтверждением. Удаление сохраняет пользовательские настройки.
- SDK, NuGet и временные файлы сборки находятся рядом с исходниками в `.acercrate-dev` на диске проекта. Эта папка не включается в архив исходников. Установленная программа сохраняет прежние системные пути настроек для совместимости.

12 ноября 2026: 690 программных тестов прошли без ошибок и пропусков после этих изменений. Блок добавления приложений убран по уточнению владельца. На главную возвращены графики температуры и загрузки CPU, полный набор находится в «Мониторинге». Клавиатура во вкладке подсветки масштабируется на доступную ширину с сохранением пропорций.

Дополнительная оптимизация интерфейса: разобранные цвета кэшируются до изменения настроек, строки дисков переиспользуются, путь изображения определяется при изменении модели или настроек. Убраны повторные обновления при загрузке главной и панели режимов. Схема питания для статуса берётся из телеметрии службы, без отдельного системного запроса из интерфейса. Объект системных настроек анимаций переиспользуется.

Ctrl+Alt+F переключает доступные режимы по кругу: Тихий → Баланс → Производительность, с учётом ограничений питания. Пассивное сообщение в форме капсулы с иконкой и названием появляется только после подтверждённой смены режима, когда главное окно скрыто или свёрнуто; оно не забирает фокус. Скруглена сама область окна, включая фон; регион переиспользуется до изменения размера/DPI. Fn+F на проверенной клавиатуре передаёт тот же scan code 0x21 и virtual key 0x46, что и обычная F, без отдельного события прошивки. Владелец выбрал Ctrl+Alt+F как замену.

В настройках приложения доступны фактический автозапуск Windows, запуск в трее и открытие клавишей NitroSense. Последний успешно применённый профиль восстанавливает управляющий компонент. При удалении сохраняются пользовательские настройки и схемы питания.

## Интерфейс

- Обычный размер окна — 1440 × 800 с учётом масштаба Windows, без свободного изменения размера. Своя кнопка разворачивает окно до рабочей области с видимой панелью задач; повторное нажатие восстанавливает размер. Свои кнопки сворачивания и закрытия, перемещение за верхнюю панель.
- Анимированное боковое меню с векторными иконками и группами «Устройство», «Мои настройки», «Система». Выбор режимов находится на главной. Доступны мониторинг, автоматизация и диагностика.
- Четвёртый режим «Мой» переименовывается в пресетах. Он хранит штатную основу, охлаждение, кривые, параметры GPU текущего профиля и, по выбору, текущую подсветку и зарядку/USB-питание. Это пользовательская комбинация, а не четвёртый режим BIOS. Схема Windows соответствует штатной основе. Тихая основа сохраняет запрет ручного охлаждения и отключает усиление/разгон.
- При видимом главном окне сообщение о смене режима не появляется. Когда окно скрыто в трей или свёрнуто, короткое сообщение показывается по центру экрана. Ctrl+Alt+4 включает личный режим, если отдельные горячие клавиши профилей включены.
- Главная: реальные датчики, физическая оперативная память Windows, сумма занятости всех доступных локальных томов с буквами дисков. Память обновляется каждые 1–3 секунды, диски — каждые 15 секунд в фоновом задании.
- На главной находятся только показания вентиляторов со шкалой 0–8000 об/мин. Ручные ползунки удалены с главной и доступны в охлаждении и личном режиме. Регулятор задаёт поддерживаемую аппаратурой добавку к автоматике 0–100%; 8000 не заявляется измеренным пределом вентилятора или прямой командой точных оборотов.
- Развёрнутые страницы используют широкую компоновку. На главной находятся показания устройства, заполнение каждого диска и два графика CPU. В пресетах и диагностике — колонки. Подсветка выбранного пункта меню находится вертикально у левого края.
- Мониторинг: шесть графиков сеткой, текущие значения и подписанные шкалы °C, %, об/мин, время каждого края графика. Высота подстраивается под окно. История хранит реальные отметки времени; данные за пределами пяти минут не рисуются. Отсутствующие показания обозначены явно.
- Тихий режим блокирует ручное охлаждение в интерфейсе и контроллере. Баланс и производительность допускают ручное охлаждение при разрешении прошивки. Температурная защита сохраняется.
- Зоны подсветки выбираются прямо на схеме клавиатуры. Всплывающий редактор содержит цвет и выключатель зоны. Изменение отдельной зоны включает статическую подсветку; штатные эффекты сохранены.
- Пресеты охлаждения и подсветки сохраняются отдельно во вкладке «Пресеты».
- В оформлении доступны свой файл, 38 встроенных фотографий моделей и выбор в настройках и отключаемый поиск фото по коду модели на сайте Acer с локальным кешем. Доступность фото всех моделей не гарантируется.
- Яркость экрана при переключении режимов сохраняется. Яркость клавиатуры регулируется отдельно.
- Заполнение индикаторов закреплено у левого края. Изменение длины плавно рисуется композитором Windows с частотой обновления экрана, включая 60 Гц, без опроса датчиков на каждом кадре. Анимация охватывает переходы к нулю и от нуля; диапазоны и измеренные значения не изменены.
- Кнопки режимов не получают серую заливку при наведении. Цветовое выделение выбранного режима плавно меняется за 240 мс; системное и пользовательское отключение анимаций учитывается.
- В свёрнутом окне и трее остановлены таймеры обновления страниц, отрисовка графиков и анимации. Показания для значка в трее обновляются раз в пять секунд, история датчиков сохраняется в ограниченном буфере; при открытии сразу показываются свежие данные. Служба управления и температурная защита продолжают работать с прежней частотой.
- При включённой настройке «Закрывать окно в трей» крестик скрывает окно даже во время подключения к устройству. Возврат — нажатием на значок в трее, кнопкой NitroSense или повторным запуском. Полный выход находится в меню трея.
- Исправлен сбой при возврате после креста: собственная кнопка больше не вызывает уничтожение окна `Window.Close()`. Системное закрытие и кнопка используют общий путь скрытия. Вызовы от NitroSense и повторного запуска ставятся в очередь интерфейса; при настоящем завершении обработчики не обращаются к уничтоженному окну.
- Новый интерфейс переведён на русский, английский и украинский, включая подсказки, статусы и ошибки. Язык выбирается в настройках, применяется при перезапуске и сохраняется. Имена пользовательских пресетов и сведения устройства остаются пользовательскими данными. Переводы исходных разделов берутся из исходных ресурсов OpenSense.
- Перед освобождением служб остановлены обновления интерфейса и анимации. Для диагностики редких ошибок WinRT сохраняются исходные управляемые стеки в `%LOCALAPPDATA%\AcerCrate\Diagnostics\ui-errors.log`; первые сообщения могут относиться к обработанным исключениям. Лог ограничен 64 уникальными записями за запуск и в архив исходников не включается.

## Сборка

Из папки исходников:

```powershell
powershell -ExecutionPolicy Bypass -File installer/Build-AcerCrate.ps1
```

Этот скрипт публикует приложение и службу, включает исходники, проверяет комплект и собирает один установщик NSIS, затем `AcerCrate.zip`. В архиве находятся папка `Source` с редактируемыми исходниками, установщик, инструкция и контрольная сумма. Пользовательские настройки и журналы из Windows в архив не включаются. При первом запуске скрипт получает проверенный по хешу компилятор NSIS. Для использования собственного компилятора передайте `-MakeNsis C:\path\makensis.exe`.

Для отдельной публикации файлов:

```powershell
dotnet publish src/AcerCrate.App/AcerCrate.App.csproj -c Release -r win-x64 -p:Platform=x64 --self-contained true -o ../AcerCrate
dotnet publish src/AcerCrate.Service/AcerCrate.Service.csproj -c Release -r win-x64 --self-contained true -o ../AcerCrate/Service
```

Публикация приложения проверяет наличие встроенной среды. Установщик отклоняет комплект, требующий отдельной установки .NET.
